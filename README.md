# Avni Gupta — Portfolio

Personal portfolio website for Avni Gupta, Technology Solutions Developer & Data Automation Specialist.

**Live site:** [https://avni-gupta.vercel.app](https://avni-portfolio-ashy.vercel.app/)

## Tech Stack
- Pure HTML, CSS, JavaScript — no frameworks, no build step
- JetBrains Mono + Syne fonts (Google Fonts)
- Fully responsive · Light/Dark mode · Custom cursor · Scroll animations

## Features
- Typewriter role animation
- Animated floating code particles
- Scroll-triggered reveals
- Progress bars
- Light / Dark theme toggle (persists via localStorage)
- Scroll progress indicator
- Active nav highlighting
- Back-to-top button

## Deploy on Vercel
1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → **Add New Project**
3. Import your GitHub repo
4. Framework Preset: **Other**
5. Click **Deploy** — done ✅
